# Hero model

`rpi-case-base.stl` and `rpi-case-top.stl` — the two-piece AIY Maker Kit
case for Raspberry Pi 4 from the google-coral/mechanicals repository
(`aiy_maker_kit/Raspberry_Pi_4/Maker_Kit_Pi4_case_base.stl` and
`Maker_Kit_Pi4_case_top_with_GPIO_cutout.stl`). Source:
https://github.com/google-coral/mechanicals/tree/master/aiy_maker_kit/Raspberry_Pi_4

Served locally so the homepage hero does not depend on a runtime CDN fetch.
